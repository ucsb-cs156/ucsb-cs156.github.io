# {{page.title}} - {{page.description}}

[<tt>{{page.title}}</tt>] is simulation game used in CHEM123.

<details markdown="1">
<summary markdown="1">Click the triangle for more details about HappyCows</summary>

### [<tt>{{page.title}}</tt>] allows instructors to:

* Create Games
* Manage Course rosters
* Assign Games to Courses
* Monitor the progress of Games

Subsequently, enrolled students and authorized staff can: 
* Join a Game
* Play the game by buying and selling cows, and observing the impact

This description is deliberately vague, because giving away too much detail may tend to reveal "spoilers" 
for the game if they are easily findable by CHEM123 students.

There are more details in the repo, however, for those with the skills to go hunting for them.

CHEM123 students are discouraged from doing so.  The object of the game isn't to win or lose, but
rather to learn some things associated with CHEM123, and it's more fun if you don't see the spoilers.
